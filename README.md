# ISO 27001 Readiness Engagement — FinFlow Ltd (Mock Client)

## Overview
This repository contains a set of GRC (Governance, Risk & Compliance) consulting deliverables
produced as a **self-directed portfolio project**, simulating an ISO/IEC 27001:2022 readiness
engagement for a fictional B2B fintech SaaS company, **FinFlow Ltd**.

> **Note:** FinFlow Ltd is a fictional company created for portfolio purposes. All data,
> risks, and controls are illustrative and do not represent any real organisation.

## Scenario
FinFlow Ltd is a fictional 40-person, fully remote B2B fintech SaaS provider offering an
invoicing and payments platform for SME customers, hosted entirely on AWS. FinFlow is
pursuing ISO 27001 certification to meet enterprise customer security due diligence
requirements — a common real-world driver for SMEs entering the ISO 27001 process.

## Deliverables

| Document | Description |
|---|---|
| [`FinFlow_ISO27001_Statement_of_Applicability.docx`](./FinFlow_ISO27001_Statement_of_Applicability.docx) | Statement of Applicability covering 25 representative ISO/IEC 27001:2022 Annex A controls, with applicability, implementation status, and justification for each. |
| [`FinFlow_ISO27001_Risk_Register.docx`](./FinFlow_ISO27001_Risk_Register.docx) | Information security risk register with 12 risks relevant to a fintech SaaS environment, scored by likelihood × impact, with treatment plans. |
| [`FinFlow_InfoSec_and_IncidentResponse_Policies.docx`](./FinFlow_InfoSec_and_IncidentResponse_Policies.docx) | Two core governance policies: Information Security Policy and Incident Response Policy. |

## Skills Demonstrated
- ISO/IEC 27001:2022 Annex A control interpretation and applicability assessment
- Information security risk assessment and treatment planning
- Governance documentation / policy writing
- Translating technical security controls into business-focused, client-ready deliverables

## Why This Project
This project was built to demonstrate practical, applied GRC consulting skills relevant to
client-facing Information Security Consultant roles, going beyond theoretical framework
knowledge to produce the actual artifacts a consultant would deliver in a real engagement.
